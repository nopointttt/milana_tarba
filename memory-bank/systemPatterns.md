# SYSTEM PATTERNS - Архитектурные решения

## Текущая задача: Реализация Технического Задания v2

### Архитектурные принципы

#### 1. Типизация запросов
**Паттерн:** Strategy Pattern для обработки разных типов запросов
- **ФИНАНСОВЫЕ ЗАПРОСЫ:** Фокус на линии денег (1-4-7), энергии для заработка
- **ВРЕМЕННЫЕ ЗАПРОСЫ:** Использование личных дат (год > месяц > день)
- **ОТНОШЕНИЯ:** Анализ линий отношений (2-5-8, 3-6-9)
- **РЕАЛИЗАЦИЯ:** Расчет сферы деятельности и рекомендации
- **ЗДОРОВЬЕ:** Анализ линий здоровья (1-2-3)

#### 2. Расчет личных дат
**Паттерн:** Chain of Responsibility для иерархии влияния
```python
# Иерархия влияния: год > месяц > день
personal_year = (day + month + current_year) % 9
personal_month = (personal_year + current_month) % 9
personal_day = (personal_month + current_day) % 9
```

#### 3. AI Integration
**Паттерн:** Template Method для специализированных промптов
- Базовый промпт + специализированные дополнения
- Контекстные данные для каждого типа запроса
- Валидация и форматирование ответов
