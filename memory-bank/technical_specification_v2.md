### 4. **ДВА РЕЖИМА РАБОТЫ**

#### **РЕЖИМ ПО УМОЛЧАНИЮ (обезличенный)**
- **Условие:** Вопрос не указывает на конкретного человека
- **Примеры:** "Что означает число 3?", "Как рассчитать матрицу?", "Расскажи про энергии"
- **Действие:** Отвечать без запроса имени и даты

#### **РЕЖИМ ПЕРСОНАЛИЗАЦИИ (с данными)**
- **Условие:** Вопрос относится к конкретному человеку
- **Примеры:** "Как мне заработать?", "Мой прогноз на год", "Моя совместимость с Марией"
- **Действие:** Запросить имя и дату, если их нет

#### **ЛОГИКА ОПРЕДЕЛЕНИЯ РЕЖИМА:**
```python
def determine_mode(user_message: str) -> str:
    # Проверяем наличие персональных местоимений и вопросов
    personal_indicators = ['мне', 'мой', 'моя', 'мое', 'я', 'меня', 'мне']
    has_personal = any(word in user_message.lower() for word in personal_indicators)
    
    if has_personal:
        return 'personalized'
    else:
        return 'default'
```

```python
def calculate_temporal_indicators(day: int, month: int, year: int, current_date: datetime) -> dict:
    personal_year = (day + month + year) % 9 or 9
    personal_month = (personal_year + current_date.month) % 9 or 9
    personal_day = (personal_month + current_date.day) % 9 or 9
    
    return {
        'personal_year': personal_year,
        'personal_month': personal_month,
        'personal_day': personal_day
    }
```
