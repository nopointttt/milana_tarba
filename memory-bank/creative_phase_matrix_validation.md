## 🎨🎨🎨 ENTERING CREATIVE PHASE: ARCHITECTURE DESIGN

### Компонент
**Система валидации и проверки матрицы энергии перед приписыванием характеристик**

### Описание проблемы
Бот приписывает пользователям характеристики энергий, которых у них НЕТ в матрице. Например:
- Ekka: бот сказал "новатор, креативный" (энергия 4), но у Ekka НЕТ энергии 4 в матрице
- Ekka: бот сказал "завершение циклов" (линия 69), но у Ekka НЕТ этой линии

### Требования
1. ✅ **Проверка матрицы**: Перед приписыванием характеристики энергии - проверить её наличие в matrix_energies
2. ✅ **Запрет на отсутствующие энергии**: НЕЛЬЗЯ описывать энергии, которых нет у пользователя
3. ✅ **Явная инструкция**: Добавить в промпты четкое требование проверять матрицу
4. ✅ **Сохранение функционала**: Бот должен продолжать работать корректно

### Шаг 2: Создание функции валидации

#### Создать в telegram-bot/src/services/matrix_validator.py:

```python
"""Функция для валидации упоминания энергий в ответе OpenAI"""

def validate_matrix_energies(response_text: str, user_matrix: dict) -> str:
    """
    Проверяет, не упомянуты ли в ответе энергии, которых нет в матрице.
    
    Args:
        response_text: Ответ от OpenAI
        user_matrix: Словарь с матрицей пользователя
        
    Returns:
        Отфильтрованный ответ без отсутствующих энергий
    """
    # Получаем список присутствующих энергий
    valid_energies = list(user_matrix.keys())
    
    # Словарь соответствия упоминаний в тексте к энергиям
    energy_keywords = {
        1: ["единица", "энергия 1", "солнце", "число 1"],
        2: ["двойка", "энергия 2", "луна", "число 2"],
        3: ["тройка", "энергия 3", "юпитер", "число 3"],
        4: ["четверка", "энергия 4", "раху", "число 4", "креативность", "новаторство"],
        # ... и так далее
    }
    
    # Проверяем каждое упоминание
    for num, keywords in energy_keywords.items():
        energy_key = f"Энергия {num}"
        
        if energy_key not in valid_energies:
            # Если энергии нет - удаляем её упоминания
            for keyword in keywords:
                response_text = response_text.replace(keyword, "")
    
    return response_text.strip()
```
