# СОВМЕСТИМОСТЬ В ОТНОШЕНИЯХ
# Источник: Книга Знаний по Цифрологии Миланы Тарба

## ОПРЕДЕЛЕНИЕ СОВМЕСТИМОСТИ
Ключевые слова: совместимость, отношения, партнерство, сравнение, анализ отношений

Совместимость определяется через сравнение:
- ЧС (Число Сознания) обоих партнеров
- ЧД (Число Действия) обоих партнеров
- Матрицы энергий обоих партнеров
- Личных дат обоих партнеров

---

## ПРИНЦИПЫ СОВМЕСТИМОСТИ

1. Сравнение ЧС показывает совместимость на уровне сознания
2. Сравнение ЧД показывает совместимость в действиях
3. Сравнение матриц показывает энергетическую совместимость
4. Личные даты показывают актуальную совместимость в конкретный период

---

## АНАЛИЗ СОВМЕСТИМОСТИ

При анализе совместимости учитывать:
- Какие энергии есть у обоих партнеров
- Какие энергии отсутствуют у обоих
- Дополняют ли партнеры друг друга
- Есть ли конфликтующие энергии

---

## ВАЖНЫЕ ПРАВИЛА

1. НЕ приписывать энергии, которых нет в матрице партнеров
2. Использовать ТОЛЬКО реальные данные из матриц
3. Учитывать личные даты для актуального периода
4. Анализировать совместимость на всех уровнях (ЧС, ЧД, матрица)
